# Инструкции для Claude

Перед работой прочитать `STATUS.md`, `AGENTS.md`, `PLAN.md`, `REQUIREMENTS.md`. Правила агентов (зоны ответственности, запись по ходу, запрет выдуманных чисел) — в `AGENTS.md`; они обязательны.

- Язык документации и отчётов — русский.
- Вспомогательные агенты (стенд, прогоны, проверки) — на модели sonnet, не более 2–3 одновременно.
- Замеры скорости в облаке (headless Chromium) — только проверка стенда, помечаются `env=desktop-headless`.
