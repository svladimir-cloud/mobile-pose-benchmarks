## 3. Метрики

Формулы — раздел 3.4 статьи. Реализация — `eval/`, с юнит-тестами на синтетических примерах.

- R3.1. **Точность:** OKS-AP/AP50/AP75/AR (pycocotools, без flip test); PCK@0,2 с нормировкой по диаметру торса; нормированная ошибка по суставам — медиана и 95-й процентиль.
- R3.2. **Полнота:** точка потеряна, если (а) модель не вернула человека, (б) score < τ, (в) координата вне кадра. FMR — доля кадров без человека; KMR_j(τ) по суставам для τ ∈ {0,1 … 0,9} + площадь под кривой + порог τ*, выровненный по 10 % пропусков; CKMR(τ, k) по суставам упражнения; длины разрывов; перестановки лево/право; «точность при полноте» (точность по найденным точкам и с потерянной точкой как ошибкой).
- R3.3. **Стабильность:** J_acc — среднее ускорение точки на статичном фрагменте и в движении, до/после фильтра 1€ (параметры фиксируются), с оценкой вносимой задержки.
- R3.4. **Производительность:** задержка инференса на кадр (включая пред-/постобработку и синхронизацию с GPU) — p50/p95 по ≥ 200 замерам после ≥ 50 прогревочных; сквозная частота кадров «камера → точки → отрисовка» и доля пропущенных кадров; холодный старт по этапам (загрузка, инициализация, первый инференс); размер модели и объём загрузки; пиковая память (если доступно); 10-минутный прогон с поминутной частотой кадров и отношением 10-я/1-я минута.
- R3.5. Доверительные интервалы — кластерный бутстреп по участникам (2000 выборок); сравнения — смешанные модели / Фридман + Уилкоксон с поправкой Холма (раздел 3.6 статьи).
